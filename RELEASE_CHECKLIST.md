**Статус: чек-лист подготовки, не объявление стабильного выпуска.**

## Что входит в памятный архив

- Полный публичный код проекта, уроки 01–06, обратные вопросы, стили, документация и тесты.
- `RELEASE_MANIFEST.json` внутри ZIP: название, девиз, версия, календарная дата выпуска, SHA исходного коммита и SHA-256 каждого файла.
- Отдельный `*.zip.sha256`: контрольная сумма самого архива для проверки спустя годы.
- Архив строится из файлов, отслеживаемых Git, и не включает приватные справочные PDF, ключи, пароли, локальные зависимости и служебную папку `dist/`.
- Содержимое можно открыть локально через `index.html`, без внешнего сервера. Книги-источники хранятся отдельно.

## Механика

**Проверка до релиза:** обычный GitHub Actions smoke workflow собирает пробный ZIP с фиктивным номером `v0.0.0` и сверяет хеши. Пробный ZIP не публикуется и не считается релизом.

**Когда автор утвердит стабильный выпуск:** создать тег `v0.1.0` на проверенном коммите либо вручную запустить workflow **«WinoWatt — памятный ZIP релиза»** с `version=v0.1.0` на `main`. Workflow сформирует `WinoWatt-v0.1.0-YYYYMMDD.zip` и `*.zip.sha256` как GitHub Actions artifacts. Для долговременного доступа отдельно прикрепить их к GitHub Release и сохранить личную копию.

**Важное различие:** ZIP из GitHub Actions не равнозначен бессрочному хранению; срок хранения artifact ограничен. GitHub Release и личный архив обеспечивают более устойчивую доступность.

Порядок релиза намеренно требует решения автора. Тег и стабильная версия **не создаются автоматически**.
