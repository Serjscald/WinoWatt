# ВиноВатт! / WinoWatt — два учебных урока (подготовительная сборка)

**Статус:** публичная предварительная версия с двумя темами для авторской проверки, **не** стабильный релиз v0.1.0.

## Как открыть

1. Распаковать ZIP-архив.
2. Открыть `index.html` в браузере (все учебные ресурсы работают локально).
3. Выбрать раздел **Введение** и одну из двух тем: «Что такое вино?» или «Характеристики и стили вина».
4. Прочитать два регистра теории: **Расскажи гостю** и **Знай как профессионал**.
5. Пройти режимы **Обучение**, **Контроль** и **Практика**.

## Что реализовано

- Пять направлений: Введение, Старый Свет, Новый Свет, Россия и Китай (заглушка).
- Во Введении предусмотрены шесть тем; **первые две содержательно заполнены**.
- Урок 01: авторская история, семь профессиональных блоков, три типичных заблуждения.
- **24 карточки** (по 12 на тему) со случайным порядком, сохранением позиции и отдельными объяснениями.
- **24 вопроса** (по 12 на тему) с перемешиванием порядка вопросов и ответов, разборами и результатом.
- **6 ситуационных задач кависта** (по три на тему) с объяснениями.
- Адаптивное оформление: графит, бордо и медные акценты; звук переключаемый.
- Изоляция ключей сохранения `vinovatt:*` от «АкадемиУма!».
- При возвращении к незавершённому обучению на том же устройстве сохраняются порядок карточек и позиция.
- Профессиональный справочник источников `SOURCES.md` и редакторские версии `LESSON_01.md`, `LESSON_02.md`.

## Ограничения

Не реализованы: четыре остальные вводные темы, содержательные курсы по географии вина, аккаунты, межустройственная синхронизация. Предварительная версия предназначена для публикации на GitHub Pages и открытого тестирования. Статус и адрес опубликованной сборки проверяются отдельно; завершённым релизом v0.1.0 она не считается. Для оценки содержания остаётся авторская редакторская проверка.

Не размещайте в публичном GitHub-коде загруженные PDF: они используются как справочная библиотека. Все тексты в прототипе написаны самостоятельно; библиографические ссылки приведены в `LESSON_01.md` и `SOURCES.md`.
