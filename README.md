# ВиноВатт! / WinoWatt — шесть учебных уроков (подготовительная сборка)

**Статус:** публичная предварительная версия с шестью темами для авторской проверки, **не** стабильный релиз v0.1.0.

## Как открыть

1. Распаковать ZIP-архив.
2. Открыть `index.html` в браузере (все учебные ресурсы работают локально).
3. Открыть раздел **Введение** и выбрать одну из шести наполненных тем.
4. Прочитать два регистра теории: **Расскажи гостю** и **Знай как профессионал**.
5. Пройти режимы **Обучение**, **Контроль** и **Практика**.

## Что реализовано

- Восемь направлений: Введение, Старый Свет, Новый Свет, Россия, Китай (заглушка), Игристые вина, Крепкие напитки (оба пока в планах) и отдельный «КофеУм для народа» (базовый справочник).
- Во Введении предусмотрены шесть тем; **все шесть содержательно заполнены**.
- Урок 01: авторская история, семь профессиональных блоков, три типичных заблуждения.
- **73 карточки** (12 + 13 + 12 + 12 + 12 + 12) со случайным порядком, сохранением позиции и отдельными объяснениями.
- **73 вопроса** (12 + 13 + 12 + 12 + 12 + 12) с перемешиванием порядка вопросов и ответов, разборами и результатом.
- **19 ситуационных задач кависта** (3 + 4 + 3 + 3 + 3 + 3) с объяснениями.
- Адаптивное оформление: графит, бордо и медные акценты; звук переключаемый.
- Изоляция ключей сохранения `vinovatt:*` от «АкадемиУма!».
- При возвращении к незавершённому обучению на том же устройстве сохраняются порядок карточек и позиция.
- Профессиональный справочник источников `SOURCES.md` и редакторские версии `LESSON_01.md` — `LESSON_06.md`.

## Ограничения

Не реализованы: содержательные курсы по географии вина, аккаунты, межустройственная синхронизация. Предварительная версия предназначена для публикации на GitHub Pages и открытого тестирования. Статус и адрес опубликованной сборки проверяются отдельно; завершённым релизом v0.1.0 она не считается. Для оценки содержания остаётся авторская редакторская проверка.

Не размещайте в публичном GitHub-коде загруженные PDF: они используются как справочная библиотека. Все тексты в прототипе написаны самостоятельно; библиографические ссылки приведены в `LESSON_01.md` и `SOURCES.md`.

Начинаем с короткой, узнаваемой метафоры; затем объясняем ощущение, подтверждаем профессиональной теорией и связываем с консультацией покупателя. ## Контроль качества перед v0.1.0

Структура первых шести уроков проверяется автоматически (`tests/content-audit.cjs`), а каждый тест урока теперь запускается CI отдельно. Отчёт о подтверждённых результатах, оставшихся задачах редактора и релизных ограничениях — `AUDIT_REPORT.md`. **Прохождение автоматических проверок не заменяет ручной проверки сценариев в мобильном браузере и предметной редакторской экспертизы.**

## Прямые и обратные вопросы — редакция 04.11.2026

Для всех шести тем подготовлены **73 авторских обратных задания** в режиме «Обучение» и **73** в режиме «Контроль». Во время прохождения половина вопросов предъявляется в прямой формулировке, половина — как распознавание термина, принципа или стиля по практической ситуации. Порядок случайный, а направление каждого вопроса в «Обучении» сохраняется вместе с прогрессом, включая совместимость с ранее сохранённым форматом.

## Памятный ZIP стабильного релиза

По утверждённому автором плану финальная версия v0.1.0 будет сопровождаться **полным архивом проекта для долговременного хранения**. Сборка выполняется `python3 tools/build_release.py --version v0.1.0`, проверка — `python3 tools/verify_release.py dist/<имя_архива>.zip`. Архив содержит манифест с версией, датой, коммитом и SHA-256 каждого файла; рядом создаётся SHA-256 всего ZIP. Порядок официального выпуска и невыполненные критерии — `RELEASE_CHECKLIST.md`. До утверждения стабильной версии выпускать архив только как тестовый, без релизного тега.

### Редакторская проверка контрольных вопросов

Всем 73 прямым контрольным вопросам переработаны неверные варианты ответов; соответствующие обратные вопросы тоже получили более содержательные варианты. См. `EDITORIAL_QUESTION_AUDIT.md` и тест `tests/distractor-quality.cjs`. Это не означает окончательной предметной приёмки курса.

У всех 19 ситуаций режима «Практика» улучшены неверные стратегии и причинные объяснения; лучшие профессиональные ответы сохранены. Отчёт — `PRACTICE_AUDIT.md`. До стабильного релиза нужна апробация с начинающими кавистами.

Отдельный восьмой раздел с шестью открытыми справочными главами: кофейное зерно, рожковая эспрессо-машина, молоко, способы приготовления, 23 распространённых напитка и сервис. Рецепты — отправные ориентиры, не обязательные для каждой машины; безопасность и чистка — по её инструкции. Редакторский документ: `COFFEEUM_GUIDE.md`.
