## Ограничение браузерной проверки

Chromium в среде подготовки блокирует переход на `file://` (и локальный HTTP); прямой браузерный прогон обновлённой сборки не завершён. Проверка живого URL на GitHub Pages выполняется отдельно после публикации. Проверку адаптивности и полные интерактивные сценарии необходимо выполнить после публикации в GitHub Pages / в браузере пользователя. Старый отчёт об уроке 01 не распространяется автоматически на обновлённую сборку.
